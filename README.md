# Gama 960+ · Landing page

Landing page da Mentoria individual de Redação ENEM 2027 do professor André Gama.

Site estático (HTML, CSS e JS puros, sem build) em [`landing/`](landing/).

## Rodar localmente

```bash
python -m http.server 5180 --directory landing
```

Depois abra http://localhost:5180.

- `landing/index.html` — versão atual
- `landing/v1/`, `landing/v3/` — versões anteriores
- `landing/docs/` — conteúdo e briefing de design
- `landing/tools/build-sprite.py` — gera o sprite de ícones SVG
